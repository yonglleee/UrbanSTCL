# UrbanSTCL — Analysis

This folder hosts analysis utilities used in this workspace.

## Contents

- `pytorch-grad-cam/`: a vendored copy of Grad-CAM utilities and tutorials.

## Tips

- If you only need Grad-CAM as a library, you can usually install it from that folder (depending on your environment):

```bash
pip install -e pytorch-grad-cam
```

- Many notebooks under `pytorch-grad-cam/tutorials/` are large; run them selectively.
